# iTrust Official Testbed Description

## Fidelity and intended use

iTrust describes Secure Water Treatment (SWaT) as a scaled-down, high-fidelity, industry-compliant emulation of a modern water-treatment facility. This supports using SWaT as an industrial cyber-physical RCA benchmark, while it does not justify inferring a case-specific failure mechanism without matching sensor and actuator evidence.
