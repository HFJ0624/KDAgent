# Verified SWaT Testbed Context

## Testbed scope

SWaT is a modern industrial control system testbed for water-treatment security research and training. The original SWaT publication describes it as a six-stage water-treatment process. This background establishes the process-level setting only; it does not identify the root cause of any experiment case.

## Control and communication architecture

According to the original SWaT publication, each process stage is autonomously controlled by a local PLC. Communication among sensors, actuators, and PLCs is realized through fieldbus channels. During RCA, a discrete actuator-state anomaly can therefore be assessed together with the continuous sensor responses in the same or connected process stages, but the temporal evidence of the current case remains the deciding evidence.

## Security experiment interpretation

The original publication presents SWaT as an environment for studying cyber-physical attacks, attack-detection algorithms, defense mechanisms, and cascading effects. Retrieved background knowledge must not be treated as an attack label, maintenance record, or ground truth for a specific case.
